# Reporting a security issue

Report sensitive security issues privately to support@mooseaillc.com. Include the app version, Android version, relevant code path and a minimal reproduction. Do not include a pairing code, private key, unredacted settings snapshot or personal device identifier.

For ordinary bugs, use the repository issue tracker with redacted examples.

Android PowerToys is currently a preview. Its wireless setup establishes a broad debugging identity after explicit pairing; a separate confirmation is required for permission grants. The app's recorded tests are not an independent security audit. Development-signed APKs and CI artifacts are not production signing-key guarantees.

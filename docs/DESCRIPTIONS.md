# Description evidence and coverage

The app combines three kinds of exact-key descriptions: individually authored safety explanations; cleaned Android 17 Settings.java Javadoc excerpts; and small consumer-verified families (AudioService persisted stream/output indices and SystemUI clock/icon/tuner keys). The source of each available description opens from the setting detail. Description text is not evidence of safe editing or a Pixel factory default.

The generated catalogue has 1,306 table/key matches from the pinned Android 17 source. Only literal declarations with adjacent prose documentation are extracted. Comments/annotations are cleaned, deprecated declarations labelled and long excerpts bounded; key spelling is never expanded into a guessed meaning. Reproduce with `python3 tools/generate_descriptions.py`. The unmodified reference, revision/hash, license and consumer references are under third_party/aosp-settings/. Curated entries override generated entries. Generated entries keep Unassessed risk, no inferred default, and an explicit distinction between documented meaning and unreviewed edit effects.

The audio catalogue contains 56 exact stream/output combinations. Stream aliasing and active-device routing mean that changing a stored index does not establish an immediate audible-volume change. Evidence: [AudioService stream construction](https://android.googlesource.com/platform/frameworks/base/+/94b4c163b7dfe5ce3607f7bb8456f9573f7de57d/services/core/java/com/android/server/audio/AudioService.java#2914), [setting-name construction](https://android.googlesource.com/platform/frameworks/base/+/94b4c163b7dfe5ce3607f7bb8456f9573f7de57d/services/core/java/com/android/server/audio/AudioService.java#10927), and [AudioSystem output names](https://android.googlesource.com/platform/frameworks/base/+/94b4c163b7dfe5ce3607f7bb8456f9573f7de57d/media/java/android/media/AudioSystem.java#1614).

Rows use three-line previews to keep browsing readable. Detail views show the full bounded entry and source link. Unknown entries remain Description unavailable. Many remaining entries are proprietary Google/Pixel, app-owned or historical bookkeeping keys without verified public consumers. No descriptions are downloaded by the app and no device values are sent to documentation sites. Coverage is measured against the provider-visible rows for this app, not the larger shell-visible set or all Android configuration; it changes with Android/user/permissions.

On the final tested Pixel build, coverage was System 66/73, Secure 132/258 and Global 184/300 provider-visible keys. See [test record](TESTING.md) for the scope. The three SystemUI consumer entries cover clock seconds, hidden icon slots and the tuner migration marker.

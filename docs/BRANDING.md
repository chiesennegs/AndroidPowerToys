# MooseAI branding

Android PowerToys uses the same MooseAI identity as OpenLifeSpan: the unmodified MooseAI moose wordmark, cyan accents, navy dark surfaces (#090D16), light surfaces (#F4F7FB), “Created by MooseAI, LLC,” mooseaillc.com and support@mooseaillc.com. Material 3 foreground/container colors are adapted for readable contrast in both themes; error colors retain their safety meaning.

The compact table toolbar includes the publisher credit within its existing height. The About page contains the logo, version, attribution and selectable contact details. Website opens the browser; Email support opens a composer and never sends automatically. Neither link opens until tapped. The launcher keeps PowerToys' distinct sliders symbol with MooseAI colors. App name, package, signing identity, permissions, stored history/baseline and editing behavior are unchanged.

Version 1.6 uses a consistent 26 sp Outfit masthead and the PowerToys app icon on all pages. Tables uses a compact header with a 48 dp minimum and keeps at least 75% scrollable space at the tested font scale; tapping its title/table area opens the table picker. Navigation has icon/label pairs. About groups support, appearance and editing setup before expandable privacy, recovery and manual-permission details. Values retain a distinct technical font for precise inspection.

Outfit font source: https://github.com/google/fonts/tree/main/ofl/outfit (SIL Open Font License 1.1, Copyright 2021 The Outfit Project Authors). Bundled unmodified variable font SHA256: fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade

Version 1.6.1 renders the app symbol on a circular background and clips the header image to a circle. Pinned search provides a 12 dp visual gap below the table header, and other pages retain a 12 dp gap below the header. The underlying MooseAI wordmark remains unchanged.
